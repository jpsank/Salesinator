- **A long repo name no longer pushes the "Change" button out of the GitHub card.** In Settings → Integrations, a repo (or account) name with no
  space or hyphen to break at kept its full width and shoved the button past the card's right edge, squashing the "Product repo" label onto two
  lines. Variable text beside a label and a button now shrinks and wraps inside the card (the Product repo line, each connection's status line,
  and their error lines), and buttons keep their size.
