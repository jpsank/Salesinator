- **Redeploys no longer leave a second, unused copy of the images on disk.** A build run without the stack's image tag (`make dev`, or compose started somewhere with no `.env`) leaves a `:dev` copy of every service image beside the running `:v012` set — gigabytes nothing runs from. `redeploy.sh` and `restart-service.sh` now remove that copy after building, leaving any image a container still uses.
